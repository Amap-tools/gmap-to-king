# Gmap 轉導航王
從 Google Maps 分享地點，自動取出座標，並打開導航王開始導航。

## 使用方式
1. 在 Google Maps 打開要去的地點。
2. 按「分享」。
3. 選擇「GmapToKing」。
短網址會在背景解開。成功後只會看到提示，接著進入導航王。

## 支援跳轉至
1. 導航王 A6
2. 導航王 3D Pro

尚未驗證是否可跳轉至導航王A5i、導航王A5i3D+
都沒裝時，才會提示先安裝導航王。

## 說明
- 傳給導航王的是座標。店名只出現在跳轉提示，不會帶進導航王。
- 無相關權限需求。不讀取位置、通訊錄、簡訊或已安裝應用程式清單，安裝與使用時不會跳出權限請求。
- 跳轉時不留在最近使用的工作清單。
